# NeuroSaarthi-AD

Multimodal dementia risk, progression, and digital-twin-lite model for the
**CBR Healthy Brain Aging AI Challenge**.

## Model Description

NeuroSaarthi-AD fuses five modalities — Cognition + Clinical, MRI, Blood
biomarkers, OCT/OCTA retinal imaging, and Genomics — using late-fusion
weighted score combination with missing-modality renormalization. It provides:

| Component                   | Purpose                                        |
| --------------------------- | ---------------------------------------------- |
| Risk Classifier (1/3/5-yr)  | Fixed-horizon dementia conversion probability  |
| Progression Regressor       | Cognitive score trajectory over time            |
| Late Fusion                 | Modality-aware score combination                |
| Twin-Lite Retriever         | Matched-trajectory retrieval for explainability |

## Intended Use

Research acceleration for dementia risk, progression modelling, cohort
enrichment, and hypothesis generation.

## Not Intended For

> [!CAUTION]
> This model is **NOT** intended for clinical diagnosis, treatment decisions,
> or direct-to-consumer screening. All current metrics are from **synthetic
> data only**.

## Training Data

The publicly released weights are trained on **840 deterministic synthetic
participants** generated by the demo module. These records are fictional.
When trained on real cohorts (ADNI, NACC, AIBL, OASIS, UK Biobank, TLSA,
SANSCOG), additional validation results will be reported.
