## 2024-05-24 - [Vectorized Survival Function Prediction]
**Learning:** Found an `O(N*M)` python loops bottleneck in predicting step functions for survival analysis (`sksurv`) inside `models/survival/cox_boost.py`. Python looping over `StepFunction` outputs from scikit-survival is extremely slow (evaluated point-by-point).
**Action:** Replace nested loops by feeding numpy arrays of bounded time points (using `np.clip` to prevent `ValueError`s from `StepFunction` out of bounds domains) directly into the `sksurv` step functions to enable vectorized extraction (e.g. `np.array([sf(safe_time_points) for sf in surv_funcs])`). This is already implemented in `rsf.py` and `gradient_boosting.py`, but missing in `cox_boost.py`, yielding an ~50x speedup in prediction.
