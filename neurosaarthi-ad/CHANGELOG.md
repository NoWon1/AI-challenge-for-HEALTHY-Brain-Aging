# Changelog

All notable changes are documented here. The project follows semantic versioning for software interfaces; research results remain tied to frozen data/split/model versions.

## 0.3.0 - 2026-08-15

- Added the Phase 0 architecture, validation, 16-week execution, and governance contract.
- Added the `neurosaarthi` package and local CLI.
- Added secure settings, redacted structured logging, protected-artifact ignore rules, and a metadata-only export audit.
- Added a configuration-driven OASIS-3 manifest adapter with keyed pseudonyms.
- Added participant/site/cohort splitters and temporal leakage assertions.
- Added NIfTI geometry, structural MRI QC, T1 preprocessing with native-space mask inversion, and morphometry.
- Added calibrated elastic-net brain-age and future-cognition baselines.
- Added regression tests and CI/container scaffolding.

No real-cohort performance is reported by this release.

## 0.2.0

- Added the synthetic multimodal dashboard, advanced tabular/survival models, ComBat, and explainability prototype.
