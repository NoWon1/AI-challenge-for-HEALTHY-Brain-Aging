# Twelve Week Roadmap

1. Scope endpoints and secure workflow.
2. Implement common data model and data dictionaries.
3. Prototype public cohort ingestion.
4. Add TLSA/SANSCOG adapters.
5. Build harmonisation and missingness dashboards.
6. Train baseline risk and survival models.
7. Add cognitive progression forecasts.
8. Add multimodal late fusion and ablations.
9. Implement twin-lite retrieval.
10. Add genomics sidecar.
11. Run external validation and subgroup checks.
12. Package dashboard, reports, model cards, and demo.
