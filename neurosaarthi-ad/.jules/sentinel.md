## 2023-10-25 - Prevented XSS in Streamlit Markdown Cards
**Vulnerability:** The `_risk_card` component in `dashboards/streamlit_app.py` rendered dynamic patient risk factors (like `horizon`, `risk`, `lower`, `upper`) into HTML structures using Streamlit's `unsafe_allow_html=True` without prior escaping.
**Learning:** `unsafe_allow_html=True` acts as a direct injection vector. While the synthetic runtime typically outputs controlled floats, any upstream validation failure or adversarial input modifying these values in a dashboard state could execute arbitrary HTML/JavaScript (CWE-79).
**Prevention:** Always wrap dynamically interpolated string variables with `html.escape()` before injecting them into HTML templates rendered by `st.markdown(..., unsafe_allow_html=True)`, even if the intended type is numeric.

## 2026-10-21 - Fixed Cross-Session State Corruption in Streamlit Cache (CWE-374 / CWE-662)
**Vulnerability:** The `ImmutableRuntimeProxy` in `dashboards/streamlit_app.py` previously only secured dictionary structures (`MappingProxyType`) from in-place modifications. Other mutable types accessed from the `@st.cache_resource` target (e.g. lists, sets, and Pandas DataFrames) were unprotected. In a multi-tenant Streamlit application, in-place mutation of these references by one user session directly modifies the global application state for all concurrent users, causing multi-tenant data leakage.
**Learning:** Returning dictionaries as mapping proxies is insufficient for full immutability. Data structures retrieved from globally cached Singletons must be evaluated recursively or thoroughly across all mutable return boundaries.
**Prevention:** Cast `list` to `tuple`, `set` to `frozenset`, and explicitly return a defensive copy (`.copy(deep=True)`) for complex mutables like `pd.DataFrame` inside the proxy's `__getattr__` method.
